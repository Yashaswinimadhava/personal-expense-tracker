
# Personal Expense Tracker

A Python command-line application for recording and analyzing personal expenses.

## Features
- Add expenses with descriptions and categories
- View expense history
- Calculate total expenses
- Summarize spending by category
- Store records locally in JSON

## Technologies
- Python
- JSON
- File handling

## How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run `python main.py`.

## Data Privacy
Expense records are stored locally in `expenses.json`.
Personal expense data should not be uploaded to GitHub.
